What's new in 4.3.1

A focused maintenance release that stops the repeated permission prompts at launch and irons out Dock shortcut icons and file previews.

No more permission prompts every launch

DockPops no longer re-asks for Desktop, Documents, and Downloads access — or keychain access — each time it starts. Once you grant access, it stays granted.

Dock shortcut icons

Renaming a Pop now updates its Dock shortcut's name to match, and Pop icon compositions rebuild reliably — including Pops with a single item or none.

File previews

Quick Look previews and file thumbnails work again for documents and folders you add to a Pop.

Readable labels

Icon labels in the popover no longer clip under the edge — longer names stay legible.
